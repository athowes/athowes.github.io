# Adam Howes - Personal Website

This is the source code for my personal website and blog, built with [Quarto](https://quarto.org/).

## Building the site

To render the site locally:

```bash
quarto render
```

To preview the site:

```bash
quarto preview
```

The rendered site is output to the `docs/` directory, which is served by GitHub Pages.
